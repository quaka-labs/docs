Quaka is a desktop harness for coding agents. It runs Claude, GPT, Gemini or a local model on your own machine, and it enforces in code what other tools only ask a model to do in a prompt.

The model can ask to run a command, edit a file, open a page or push a branch. Quaka decides what reaches the machine, what happens when it does, and what a run has to show before it can call itself done.

## The short version

A fresh install is already opinionated. Shell commands run in the operating system's sandbox. A run that starts from someone else's text works in a copy. A Build run that changed files has to pass the repository's checks. A side effect that leaves the project asks you first.

That is the default posture. Every setting that changes it is documented, and every security page ends with what the layer does not cover.
